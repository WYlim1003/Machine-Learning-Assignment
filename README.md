# 🚆 KTMB Komuter Ridership Prediction

## 📌 Project Overview
This project focuses on predicting the **Ridership Per Hour** for the KTMB Komuter service using various machine learning techniques. By analyzing independent features such as **time, origin, and destination**, the model aims to provide accurate forecasts that can assist in **transit planning and resource allocation**.

---

## 🎯 Problem Statement
The primary goal is to **predict the ridership per hour based on independent features**. Understanding passenger flow at an hourly frequency is critical for:
- Optimizing train schedules  
- Improving commuter experience  
- Enhancing resource allocation  

---

## 📊 Dataset & Features
The analysis is based on the **Hourly Origin-Destination Ridership dataset** for Komuter services.
